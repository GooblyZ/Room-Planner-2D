Quick walkthrough
  1. Left‑click or touch an item to select and drag it. Use the mouse wheel or pinch to zoom the plan.
  2. To create new furniture, enter a name and dimensions in the New furniture section or pick from the built‑in list of standard items via the dropdown suggestions. You can also toggle Draw with mouse to draw a rectangle directly on the canvas.
  3. Switch between units (centimetres, feet or inches) using the Units dropdown in Room settings. All measurements update automatically.
  4. Toggle Room design mode to draw additional room segments. Finish the drag to add the segment to the room shape.
  5. Use the live measurements displayed while dragging to see the size of your furniture and distances to walls or nearby objects. Items snap gently to the grid when close to a grid line.
  6. If something goes wrong, press Undo (Ctrl+Z) or Redo (Ctrl+Shift+Z). Undo/Redo now fully supports room design additions and polygon shapes.
  7. Open this tutorial again anytime via the Show tutorial button.

Usage tips

  • Left click an item to select and drag it.
  • Drag on empty space to pan the view.
  • Mouse wheel zooms at cursor.
  • Draw mode lets you create items by dragging a rectangle.
  • Items can not overlap other items.
  • Merge joins two touching items to one L shape with two blocks.
  • Undo and Redo affect add, delete, move, rotate and merge.
