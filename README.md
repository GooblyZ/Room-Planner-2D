# 2D Room Planner

A dependency-free, single-page room planning tool built on HTML5 Canvas.

## Why this repo exists
This project is intentionally kept framework-free: it runs locally by opening `index.html`.
For maintainability and credibility, the original single-file prototype was split into:
- `index.html` (markup)
- `styles.css` (UI styling)
- `app.js` (application logic)

## Run locally
- Open `index.html` in a browser.

## Notes
- PDF export uses jsPDF via CDN.
- The Vercel Analytics snippets are included but optional. If you deploy on GitHub Pages, you can remove them safely.
